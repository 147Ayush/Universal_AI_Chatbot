Universal AI Chatbot is a full-stack, multi-provider AI assistant platform inspired by ChatGPT and Claude. It supports OpenAI, Groq, and Google Gemini through a unified provider layer, with agent orchestration via LangGraph, external tool access via MCP, short- and long-term memory, streaming responses, retrieval-augmented generation (RAG), and a modern React + TypeScript interface. Built as a modular, production-oriented reference architecture rather than a demo — with clean separation between API, service, orchestration, and provider layers.
